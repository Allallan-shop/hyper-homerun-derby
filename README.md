### 採用技術と制作方針

- TypeScript + Phaser 3 + Vite を基本構成に採用。ブラウザの静的配信を第一候補とし、Steamは後から判断。
- ステージ数・投手・難易度・画像・BGM・効果音・ボイスは簡単に入れ替えられるようにする。
- 原作寄りのマウス打撃、ポイント強化、全ステージ通しの実経過時間、実プレイ成績によるレーダー、X向け画像リザルトが中核。
- システム開発規模の目標は約1週間。微細な不具合・演出違和感を過剰に修正せず、遊べるゲームの完成を最優先する。
- 高難易度モードは通常モードクリア後にタイトルから選択する追加候補で、最小完成に必須ではない。
