## 設計・進行

- [Issue #1 — 設計確定チェックリスト](https://github.com/Allallan-shop/hyper-homerun-derby/issues/1)
- システム開発は約1週間で収める規模を目標とし、他の優先タスクを圧迫しない。
- ステージ数・難易度・キャラクター・画像・音声を柔軟に変更できる構成を検討する。
- 通常クリア後にタイトル画面から選択できる高難易度モードの追加余地を残す。
- 詳細リザルト、画像化、SNS共有を重視する。
- ブラウザとSteamを含む公開方法は設計段階で比較・決定する。

現段階の上記は**企画上の方針**であり、ライブラリ、エンジン、仕様を確定するものではありません。
